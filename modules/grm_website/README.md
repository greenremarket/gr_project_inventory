# grm_website

This Odoo module extends website functionality for the Greenremarket project.

## Features

- Customizes the website appearance and behavior.
- Adds new pages, templates, or controllers as required by your project.
- Integrates with other GRM modules for seamless user experience.

## Usage

After installing, access your website from the Odoo frontend. Any new features or pages provided by the module will be available automatically.

## How to Manage Website Content

1. Go to the **Website** app in Odoo.
2. Use the editor to add or modify pages, blocks, or menus.
3. If your module provides custom templates or snippets, find them in the website builder sidebar.
4. Save and publish your changes.

## Installation

1. Place the `grm_website` directory in your Odoo addons path.
2. Update the Odoo app list and install the module from the Apps menu.
